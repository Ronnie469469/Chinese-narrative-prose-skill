# Narrative Prose

一个用于生成、改写和自检中文叙事散文的 Codex Skill。

它将公开资料中提炼出的新概念作文写作理念，与通用散文结构、场景写作、情绪推进和文章修改方法结合起来，形成一套可以重复调用的中文长篇散文写作系统。

## 核心功能

- 生成中文叙事散文和长文案
- 改写已有文章
- 检查文章的叙事、细节、情绪、语言和结尾
- 根据题材自动选择散文模式
- 默认生成约 2500-4000 字的中文正文

支持的主题模式包括：

- 成长与回望
- 故乡与离开
- 亲情与家庭
- 青春关系与错过
- 城市生活与孤独
- 日常生活中的社会观察

## 风格特点

这个 Skill 不是对某一位作者或某一篇作品进行仿写，而是预先提炼一套可复用的写作原则：

- 从具体生活细节切入
- 用物件、动作、场景和感官细节承载情绪
- 让个人经验逐渐通向更大的观察
- 让情绪在叙事中积累，而不是直接喊出来
- 保持文学性，但避免堆砌辞藻
- 使用有变化的句子节奏
- 让结尾回到前文的物件、动作或场景
- 避免空泛哲理、鸡汤式总结和强行升华

## 使用方式

显式调用：

```text
$narrative-prose
```

### 生成文章

```text
$narrative-prose

主题：离开故乡
素材：我大学毕业后第一次回到家乡，发现老房子已经被重新装修，父亲还保留着我小时候用过的书桌。
目标情绪：克制、缓慢、后劲强
篇幅：约3000字
```

### 改写文章

```text
$narrative-prose

请改写下面这篇文章。

要求：
- 保留事实和核心情绪
- 增加具体场景和生活细节
- 减少空泛抒情
- 让结尾更自然

原文：
……
```

### 文章自检

```text
$narrative-prose

请检查下面这篇文章：

- 是否有完整叙事
- 是否有具体细节
- 情绪是否过度
- 是否存在模板化表达
- 结尾是否有效

文章：
……
```

## 默认输出

当用户没有指定其他格式时，Skill 默认输出：

1. 文章命题
2. 叙事提纲
3. 完整正文
